# CODEXTECH 🚀

**Ideas are where it starts. Innovation is what we build.**

CODEXTECH is a team project built around creativity, technology, and collaboration. We wanted to create more than a regular team portfolio, so we designed an interactive experience where visitors can explore our team through cinematic introductions, animated transitions, and individual profiles.

🌐 **Live Website:** [code-x-tech-five.vercel.app](https://code-x-tech-five.vercel.app/)

💻 **Source Code:** [GitHub Repository](https://github.com/Sumit-Kumar-Panigrahi/CodeXTech)

## ✨ What makes it special?

- **A cinematic welcome:** An animated introduction that brings the CODEXTECH identity to life.
- **Interactive team profiles:** Get to know the people behind the project and what each member contributes.
- **Voice introductions:** Audio-based introductions make exploring the team more engaging.
- **Animated dashboard:** A smooth dashboard reveal with a matching cinematic sound effect.
- **A consistent experience:** Local audio assets help keep narration consistent across browsers and devices.
- **Modern design:** A dark visual theme, bold typography, smooth transitions, and carefully designed interactions.
- **Responsive layout:** Designed to provide a good experience across different screen sizes.

## 💻 Run It Locally

Want to explore the project or run it on your machine? Follow these steps.

### Prerequisites

Install [Node.js](https://nodejs.org/) and Git before getting started.

### 1. Clone the repository

```bash
git clone https://github.com/Sumit-Kumar-Panigrahi/CodeXTech.git
```

### 2. Open the project folder

```bash
cd CodeXTech
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to explore the website.

## 🏗️ Production Build

Check whether the project builds successfully:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🔊 Audio Experience

CODEXTECH uses audio assets for its welcome narration, team introductions, and dashboard transition sound.

The project includes assets such as:

- `public/assets/audio/welcome-intro.mp3`
- `public/assets/audio/dashboard-reveal.mp3`

The actual playback behavior depends on the implemented audio controls and browser permissions. Browsers may require user interaction before allowing audio to play.

## 🚀 Deployment

The website is hosted on Vercel.

**Visit the live project:** https://code-x-tech-five.vercel.app/

When the GitHub repository is connected to Vercel with automatic deployments enabled, pushing updates to the configured branch can trigger a new deployment.
